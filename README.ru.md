# UnRepost — Инструмент пакетного удаления репостов TikTok

[English Version](README.md) | [Политика конфиденциальности (Privacy Policy)](PRIVACY.md) | [Безопасность (Security Policy)](SECURITY.md)

**UnRepost** — это бесплатный инструмент автоматизации с открытым исходным кодом, предназначенный для безопасного и пошагового удаления собственных репостов в TikTok непосредственно с вашего компьютера.

- **Пароли и данные авторизации не передаются разработчику**: Вы авторизуетесь в обычном окне браузера. UnRepost не перехватывает и никуда не отправляет пароли или сессии.
- **100% бесплатно и Open-Source**: Без подписок, платных API, сторонних прокси-серверов и телеметрии.
- **Работа только локально**: Сервер запускается исключительно на интерфейсе `127.0.0.1` (loopback) с валидацией источника (Origin) для защиты от CSRF-атак.
- **Двухэтапная проверка удаления**: Алгоритм строго отличает реальное подтверждение удаления сервером TikTok (`delete_video_status === 1`) от скрытых троттлингов и пустых ответов при лимитах.
- **Безопасный ночной режим**: Задержки с рандомизацией под поведение человека (3.0 – 5.5 сек), звуковые уведомления о капче, ожидание при временных ограничениях и сохранение прогресса в реальном времени.

## ⚠️ Важное предупреждение и платформенные ограничения

> [!WARNING]
> - **Действие необратимо**: Удаление репостов обратно не отменяется. Восстановить удалённые репосты автоматически невозможно.
> - **Ограничения платформы**: У TikTok нет публичного официального API для управления репостами. Инструмент взаимодействует с внутренними веб-эндпоинтами, на которые распространяются лимиты частоты запросов, антиспам-фильтры и проверки капчи.
> - **Отсутствие гарантий**: Невозможно гарантировать 100% удаление во всех ситуациях или полное отсутствие временных ограничений со стороны платформы. При удалении большого объёма репостов TikTok может временно приостановить действие до сброса суточного лимита.
> - **Независимый проект**: UnRepost не связан, не авторизован, не поддерживается и не спонсируется TikTok, ByteDance или их аффилированными лицами.

## 🚀 Установка и запуск

### Способ 1: Приложение для macOS (запуск в два клика)

Для обычных пользователей macOS, которым нужен графический интерфейс без работы с терминалом:

1. Скачайте архив со страницы [Releases](https://github.com/lansixxx/UnRepost/releases).
2. Распакуйте архив и найдите приложение `UnRepost.app`.
3. Запустите `UnRepost.app` двойным кликом.
   - *Примечание о защите macOS (Gatekeeper)*: Поскольку это бесплатный open-source проект без платного сертификата Apple Developer, при первом открытии macOS может показать предупреждение: *"Не удается проверить разработчика"*.
   - Как открыть: Нажмите правой кнопкой мыши (или Control + клик) на `UnRepost.app`, выберите **«Открыть»** и подтвердите запуск. Либо выполните в Терминале: `xattr -cr /путь/к/UnRepost.app`.
4. Убедитесь, что на компьютере установлен Google Chrome или Chromium. UnRepost откроет отдельное окно интерфейса.

### Способ 2: Запуск из исходного кода (macOS, Windows, Linux)

Для разработчиков и пользователей Windows/Linux:

#### Системные требования
- [Node.js](https://nodejs.org/) (версия 18 или выше)
- Установленный Google Chrome или Chromium

#### Шаги установки
```bash
# Клонируйте репозиторий
git clone https://github.com/lansixxx/UnRepost.git
cd unrepost

# Установите зависимости
npm install

# Запустите тесты
npm test

# Запустите приложение
npm start
```
Откройте адрес `http://127.0.0.1:3210` в вашем браузере.

## 📋 Порядок работы

1. **Вход в аккаунт**: Авторизуйтесь в открывшемся окне браузера TikTok (по QR-коду, телефону, почте или соцсетям). UnRepost определит ваш аккаунт локально, не запрашивая пароль.
2. **Предварительный просмотр (Pre-Scan)**: Нажмите кнопку **«Просканировать репосты (Pre-Scan)»**, чтобы оценить общее количество репостов без отправки запросов на их удаление.
3. **Запуск удаления**: Установите галочку подтверждения и нажмите кнопку **«Подтвердить и начать удаление»**. UnRepost будет поочерёдно снимать репосты с человеческими паузами.
4. **Пауза и возобновление**: Вы можете нажать **Пауза** в любой момент. Прогресс записывается на диск после каждого видео, поэтому приложение можно закрывать и запускать заново без потери истории.
5. **Выход и очистка**: Кнопка **«Выйти и очистить сессию»** позволяет полностью удалить локальные куки и файлы кэша с компьютера.

## 🔒 Конфиденциальность и хранение данных

- **Локальные каталоги пользователя**: Сессия и файл состояния хранятся в стандартных системных директориях:
  - macOS: `~/Library/Application Support/UnRepost`
  - Windows: `%APPDATA%\UnRepost`
  - Linux: `~/.config/unrepost`
- **Защита сетевого контура**: Сервер слушает только локальный IP `127.0.0.1`. Любые запросы с внешними заголовками Host или Cross-Origin блокируются кодом `403 Forbidden`.
- **Без сторонних запросов**: Весь обмен данными происходит исключительно между вашим компьютером и серверами `tiktok.com`. Никакой телеметрии и аналитики.
- **Экспорт журнала**: Скачивание CSV и JSON отчётов происходит только по прямому подтверждению пользователя.

Подробнее читайте в [Политике конфиденциальности (PRIVACY.md)](PRIVACY.md) и [Политике безопасности (SECURITY.md)](SECURITY.md).
